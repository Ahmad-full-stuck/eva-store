# ماشا — متجر ملابس أطفال

واجهة ماشا تحتفظ بهويتها البصرية المستقلة (العاجي والأخضر الهادئ والذهبي الدافئ) وتستعيد وظائف المتجر الأساسية: تصفح المنتجات، البحث والتصنيف والترتيب، صور المنتج ومواصفاته، المقاس واللون، المفضلة، الحقيبة، إكمال الطلب، تتبّع الطلب، السياسات، التواصل وصندوق الاستفسارات ولوحة إدارة.

## المسارات

- الواجهة: `artifacts/masha-store`
- خدمة API وقاعدة البيانات المنفصلتان: `artifacts/masha-worker`
- قاعدة بيانات ماشا: Cloudflare D1 باسم `masha-store-db`، مستقلة عن قاعدة إيفا.
- رابط GitHub Pages الحالي: `https://ahmad-full-stuck.github.io/eva-store/masha/`
- نقطة API: `https://masha-store.eva-store.workers.dev`

## التطوير والبناء

من جذر مساحة العمل:

- `pnpm --filter @workspace/masha-store typecheck`
- `pnpm --filter @workspace/masha-store build`
- `pnpm --filter @workspace/masha-store dev`
- `pnpm --filter @workspace/masha-worker typecheck`

يستخدم البناء `VITE_MASHA_API_BASE_URL` لتحديد API الخاص بماشا. يقوم سير عمل Cloudflare بإنشاء/إيجاد قاعدة ماشا المنفصلة، تطبيق ملفات `migrations`، وبناء واجهة مستقلة لخدمة Worker. إذا تعذّر اتصال API، تحتفظ الواجهة بوضع معاينة احتياطي بدلاً من تعطّل التصميم.

## الإدارة

تدعم لوحة الإدارة المتصلة تعديل المنتجات، الإخفاء والحذف، الصور الإضافية والفيديو والمخزون، استيراد/تصدير JSON، مراجعة الطلبات وتحديث حالاتها، صندوق الاستفسارات، وأجرة التوصيل وحد التوصيل المجاني ورسالة المتجر ورقم واتساب. عند تسجيل دخول الإدارة، تُحفظ التغييرات في قاعدة ماشا لا قاعدة إيفا.

لتمكين تسجيل دخول الإدارة على الخادم، أضف سر GitHub Actions باسم `MASHA_ADMIN_PIN` في إعدادات المستودع (Settings → Secrets and variables → Actions). يجب أن يكون رمزاً خاصاً مكوناً من 4 إلى 12 رقماً. إذا لم يُضبط السر، يبقى API العام متاحاً وتبقى لوحة المعاينة المحلية موضحةً على أنها غير إنتاجية؛ لن يوجد تسجيل دخول إداري مركزي.

## الطلبات والمخزون

يعيد الخادم حساب الأسعار من كتالوج ماشا ولا يثق بالمجموع الذي يرسله المتصفح. تتحقق قاعدة البيانات من المخزون وتحجز الكميات عند تسجيل الطلب، وتعيد المتاح عند إلغاء طلب قبل الشحن. رسوم التوصيل وحد التوصيل المجاني تُؤخذ من إعدادات المتجر على الخادم. يظل إرسال رسالة واتساب أو إنستغرام خطوة منفصلة يجب على الزائر إتمامها داخل التطبيق؛ تسجيل الطلب لا يعني أن الرسالة الخارجية أُرسلت.

## تنبيه عن بيانات العرض

المنتجات الثمانية في migration `0005_masha_seed.sql` وملف `src/lib/products.json` بيانات تجريبية: أسماء وأسعار وأعمار وألوان وصور من مصادر عامة، وليست كتالوجاً مستخرجاً من حساب ماشا. لا تعتمدها للبيع قبل استبدالها ببيانات وصور وأسعار ومخزون معتمدة من صاحب المتجر. سياسات التوصيل والاسترجاع النهائية تحتاج موافقة صاحب المتجر كذلك.

روابط `instagramVideoUrl` تستخدم المشغل المضمّن للروابط العامة القابلة للتضمين؛ لا يحاول المشروع تجاوز تسجيل الدخول أو تحويل روابط إنستغرام إلى ملفات MP4.

## الخصوصية والأمان

لا يشارك هذا المشروع قاعدة إيفا أو جلساتها أو بيانات طلباتها. لا تضع أسرار Cloudflare أو رمز الإدارة داخل الشفرة أو متغيرات `VITE_*`. مفاتيح النشر تبقى في GitHub Actions Secrets. نسخة المعاينة المحلية تعمل على الجهاز والمتصفح نفسيهما، وليست قاعدة بيانات مشتركة.
