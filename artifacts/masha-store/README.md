# ماشا — متجر ملابس أطفال

نسخة مشتقة من تطبيق Eva Store الأصلي، محفوظة في مجلد مستقل على فرع masha-store. لم تتغير ملفات إيفا الأصلية.

## التشغيل من جذر مساحة العمل
- pnpm --filter @workspace/masha-store typecheck
- pnpm --filter @workspace/masha-store build
- pnpm --filter @workspace/masha-store dev

## الموجود في نسخة العرض
واجهة RTL متجاوبة، بحث وتصنيف، تفاصيل المنتج واختيار المقاس، المفضلة، حقيبة مشتريات محفوظة محليًا، وتجهيز ملخص طلب. إذا ضُبط VITE_WHATSAPP_NUMBER يفتح WhatsApp؛ وإلا ينسخ الملخص ويفتح حساب إنستغرام.

## تنبيه
المنتجات والأسعار والصور الحالية بيانات تجريبية غير مستخرجة من حساب ماشا. استبدلها بالبيانات المؤكدة قبل النشر. لا يوجد backend أو قاعدة بيانات مستقلة متصلة في هذه النسخة؛ localStorage ليس قاعدة إنتاجية.

استيراد بيانات المنتجات: من مجلد artifacts/masha-store شغّل node scripts/import-products.mjs src/lib/products.json بعد تعديل src/lib/products.json أو استبداله ببيانات موثوقة؛ السكربت يتحقق من الروابط والأسعار والمقاسات ثم يعيد كتابة الكتالوج. خذ نسخة احتياطية قبل الاستيراد. خذ نسخة احتياطية من الكتالوج أولاً.

حقل instagramVideoUrl يقبل رابط Reel أو Post عام. لا يمكن تحويل رابط صفحة إنستغرام إلى MP4 مباشرة؛ يستخدم الموقع مشغل Instagram المضمّن حين يسمح إنستغرام بذلك. سكربت الاستيراد لا يكشط الحساب ولا يتجاوز قيود الدخول.
