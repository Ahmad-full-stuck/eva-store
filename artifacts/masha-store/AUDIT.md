# مراجعة هندسية لمتجر ماشا

هذه المراجعة تصف الملفات الحالية والمتطلبات التي لا تزال تحتاج اعتماداً أو اختباراً؛ لا تدّعي إجراء اختبار يدوي على جميع الشاشات أو اختبار اختراق إنتاجي.

## التصميم وتجربة المستخدم
- الهوية البصرية الخاصة بماشا مستقلة عن واجهة إيفا: عاجي وأخضر هادئ ولمسات ذهبية، RTL، مع تخطيط متجاوب.
- تتضمن الصفحات: الرئيسية، الكتالوج، المفضلة، معلومات المنتج، الحقيبة، إكمال الطلب، تأكيد الطلب، تتبع الطلب، دليل المقاسات، من نحن، التواصل، السياسات ولوحة الإدارة.
- تتضمن الواجهة بحثاً عربياً مطبّعاً، تصنيفاً، ترتيباً بالسعر أو الاسم، معرض صور، مواصفات الخامة والعناية، اختيار المقاس واللون، رسائل حالة واضحة، وأدوات لوحة إدارة.
- يلزم اختبار مرئي على عرض 320/375/768/1440 بكسل، قارئ شاشة، لوحة المفاتيح وتكبير النص.

## التجارة والطلبات
- ينشئ Worker المخصص لماشا طلبات في D1 منفصلة، ويعيد حساب السعر من كتالوج الخادم.
- تتحقق قاعدة البيانات من المخزون وتحجز الكمية ذرياً عند إدخال الطلب؛ يلزم اختبار الطلبات المتزامنة، الإلغاء، وإعادة تفعيل الطلب الملغى.
- رسوم التوصيل وحد المجاني قابلان للضبط من إعدادات خادم ماشا. القيم الافتراضية صفر؛ على صاحب المتجر تعيين السياسة الواقعية قبل الطلبات الحقيقية.
- رسالة WhatsApp/Instagram ليست إرسالاً تلقائياً؛ المتصفح يفتح الخدمة الخارجية، ويلزم الزائر الضغط على إرسال.
- المخزون في المنتجات التجريبية مبدئي وليس مخزون ماشا الحقيقي؛ استبدله قبل النشر التجاري.

## قاعدة البيانات والخدمة
- يوجد Worker مخصص باسم `masha-store` وقاعدة D1 باسم `masha-store-db`; لا يستخدم قاعدة إيفا.
- المهاجرات 0001–0004 تهيئ الجداول العامة، و0005 تضيف كتالوج العرض، و0006 تحجز/تعيد الكمية مع دورة الطلب.
- API الإدارة يدعم المنتجات والطلبات والإعدادات والرسائل والصور والإحصاءات وفق ملفات خدمة ماشا.
- كتالوج API العام يُخزّن مؤقتاً؛ يجب أن يؤدي تغيير المخزون/الطلب إلى تحديث ذاكرة الكتالوج.
- يلزم التحقق من نجاح سير عمل Cloudflare وسير عمل Pages على أحدث commit قبل اعتماد الرابط كمنشور.

## الأمن والخصوصية
- لا يوجد رمز مدير افتراضي مضمّن. يجب توفير `MASHA_ADMIN_PIN` كـ GitHub Actions Secret لتفعيل دخول الإدارة؛ دون ذلك ستظهر رسالة بأن الإدارة المركزية غير مفعّلة.
- لا تضع مفاتيح Cloudflare أو رمز الإدارة في الشفرة أو متغيرات `VITE_*`.
- واجهة المعاينة المحلية محفوظة بوضوح على أنها محلية فقط. بيانات الطلبات التجريبية/القديمة في localStorage قد تبقى على جهاز المستخدم حتى تُمسح يدوياً.
- يلزم اختبار rate limiting، رفض الطلبات المكررة، الحمولات غير الصالحة، حدود الصور، CORS، صلاحية الجلسات، وأخطاء انقطاع الشبكة.

## SEO والأداء
- تمت إضافة عناوين وأوصاف للصفحات من الواجهة؛ لا يزال يلزم إكمال canonical وOpen Graph وsitemap وبيانات المنتج المنظمة بعد تحديد النطاق النهائي.
- صور العرض الحالية ليست أصول ماشا المعتمدة. استبدلها بصور المنتج المضبوطة مع نصوص بديلة واقعية.
- راجع الأداء على اتصال بطيء، وسلوك ذاكرة التخزين المؤقت بعد تعديل الأسعار والمخزون.
