# Eva Store — Client storefronts

Five independent brand storefronts are maintained inside the existing Eva Store repository. Each brand has its own configuration, mobile-ready page shell, short Cloudflare Worker hostname and shared Workers KV order namespace with per-store key prefixes. The shared Worker runtime serves the individual brand folder; the original Eva fabric store remains separate.

Brands: BRAND_LAYA, مكتب النجوم للهواتف النقالة, شركة لنا, SCOOPER and MUKHTAR.
