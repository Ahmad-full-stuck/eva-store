## الملاحظات والإصلاحات بالتفصيل

### F1 — مسارات `path` ترجع 404 (مُصنَّفة الآن: سلوك مقصود — أُغلقت كإخفاق)
- `GET /catalog`, `/cart`, `/product/staylat` … → HTTP 404 (صفحة GitHub، 9379 بايت بلا `id="root"`).
- **السبب:** التوجيه بالـ hash مقصود (`main.tsx:16` يستخدم `useHashLocation`؛ `src/lib/hash-location.ts:21` يقرأ `location.hash`)، والروابط الصحيحة كلها `/#/...` وتعمل 14/14. التطبيق نفسه **لا ينتج أي رابط `path`**، لذا ليس هناك رابط داخلي ينكسر.
- **ليس عطلاً وظيفياً.** تحسين اختياري غير مُنفَّذ: `404.html` ينسخ `index.html` ليبدو زيارة المسار اليدوي كصفحة رئيسية بدل صفحة GitHub — الفائدة هامشية لأن الـ SEO لا يخدم روابط hash أصلاً.

### F2 — المنتجان المخفيان داخل الحزمة (مُصنَّف الآن: مقبول — أُغلق)
- السجلان موجودان كبيانات خام مع `"hidden":true` في الحزمة، لكن `src/lib/fallback-data.ts:7,11` يزيل أي `hidden === true` قبل العرض: **لا يظهران في أي واجهة أو رابط أو سitemap**.
- في حزمة ثابتة (بلا خادم) يستحيل ترميزهما خارجياً دون API؛ المعيار الوظيفي «عدم ظهورهما» محقق.

### F3 — sitemap.xml بلا روابط منتجات (جزئي — ملاحظة SEO محدودة الأثر)
- المحتوى: عنصر `<url>` واحد (الصفحة الرئيسية) وهو المُفهرس فعلياً.
